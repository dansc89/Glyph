# Glyph 1.5

A reliability-focused update for the compact native PDF editor on x86_64 Linux.

## Changes

- Heavy pages show an animated loading indicator and the actual page number instead of suggesting the PDF was closed. Failed previews show an unavailable state.
- Save, Save As, editing and markup loading have operation-owned status. Successful disk commit is distinguished from subsequent preview refresh.
- Operations overdue by ten seconds show a warning without cancelling workers, releasing owned sessions or clearing unsaved changes.
- A stopped renderer produces a persistent diagnostic instead of indefinite loading. The document and editable session are retained; new mutations are blocked, while owned changes can still be saved. Preview restoration requires restarting Glyph.
- Fixed post-save/dead-renderer and stale saved-preview-token recovery edge cases. Current pixels release the preview gate; stale results cannot clear current ownership.
- High-zoom pans reuse valid padded tiles. A controlled 60-step sequence scheduled 7 tile jobs rather than 60; this is a work-reduction measurement, not a universal frame-rate claim.
- Double-click selects and copies the whole word. Native drag selection and hyperlink routing remain covered.

## Verification

The reviewed development source passed 335 portable Rust tests, formatting, strict all-target Clippy and optimized compilation. Two private drawing tests are intentionally excluded; private drawings are not uploaded. Generated native checks cover loading, save-stage feedback, original PDF content/annotation preservation, backups, repeated Save, read-only refusal/retry, viewport/navigation/search/copy and display isolation.

Release publication is gated on fresh exact-source local checks and exact-commit GitHub Actions quality, native reliability, runtime dependency and packaging checks. Downloaded distribution packages and uploaded assets are verified against SHA256; the downloaded AppImage payload is tested on an owned display before publication.

## Limits

These changes improve feedback and tested recovery, not guaranteed crash-free operation or bounded filesystem/PDFium waits. An overdue warning does not forcibly recover a live blocked worker. This is not complete Drawbridge parity or proof of the fastest editor on Arch/Omarchy. Dense-text extraction/hit testing, background scheduling, idle CPU, native Wayland/mixed-DPI and representative drawing-set validation remain follow-up work. Reversible Flatten/Unflatten and lossless Reduce remain unfinished.

## Downloads

Arch-first `glyph-arch-x86_64.tar.gz` and `install-glyph-arch.sh`; alternate `Glyph-x86_64.AppImage` and no-FUSE installer; Debian package and compatibility tarball. `SHA256SUMS` covers distribution assets.

Publishing does not install or launch the app on the user's desktop or modify user PDFs.
