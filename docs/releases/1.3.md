# Glyph 1.3

Native PDF markup and safer editing/save workflows for x86_64 Linux. This release advances Drawbridge v4.8 parity; it does not claim complete feature parity or equal production stability.

## Changes

- Draw native PDF rectangles (`R`) and ellipses (`E`); select with `V`, Delete, and shared Undo/Redo. Saved markups have explicit PDF appearance streams and remain visible/selectable after reopen.
- Geometry-aware ellipse selection: empty bounding-box corners no longer select or authorize deletion. Current-page, topmost-shape and layer ownership guards remain intact.
- Background in-memory editing with PDFium byte-snapshot previews. Unsaved edits do not rewrite the source PDF. Dirty/history state survives preview or Save failure; stale-canvas mutation is blocked until a valid preview recovers.
- Editable bookmark titles and embedded page labels, shared Undo/Redo and guarded Save/Save As. Save uses staged semantic verification, source-change checks, Linux atomic replacement and retained original backups. Save As refuses destination collisions.
- Corrected false Save/Save As rejection for valid integral-real PDF values normalized by serialization, without relaxing general object-preservation checks.
- Corrected finishing-markup loss when pointer release and the Save shortcut arrive in the same UI frame.
- Improved native layout/input handling, preview scheduling and isolated GUI QA. Existing text search, internal links, virtualized thumbnails, text copying, selectable-text sheet-ID automation and Omarchy palette integration remain available.

## Verification

- The reviewed development source passed 291 Rust tests including ignored regressions, formatting, strict all-target Clippy, and optimized compilation.
- The preceding exact-source native build passed 96 freshly executed markup/save assertions plus layout/usability checks, using owned Xvfb displays rather than the user desktop.
- Added a synthetic backend workload: 100 pages, 200 mixed markups, inherited crop/four rotations, seven Saves, one Save As, shared-history checkpoints, read-only rejection/retry and destination collisions. Original content/resources/foreign annotations and exact backups are checked.
- A separate synthetic native workload loads 100 pages/200 existing markups, draws and saves three more, and reopens all 203. Independent pypdf checks preserve original text, content streams, geometry, links and markup appearances; untouched pages 2 and 100 rendered pixel-identically with Poppler.
- Independent source reviews found no blocking issues. GitHub Actions gates distribution artifacts on formatting, Clippy, tests, optimized build, GUI/viewer regressions, markup save/recovery, synthetic native save stress, display-isolation tests, runtime dependency checks and packaging.

## Limits

- Synthetic fixtures are not a production architectural/civil corpus. No guarantee of crash-free operation, production save speed or stability equal to Drawbridge.
- Line, arrow, text, polyline/polygon, move/resize, style controls, OCR/title-block review, reversible Flatten/Unflatten and lossless Reduce remain unfinished. Unsafe legacy Flatten remains disabled.
- Undo history is bounded to 64 changes, but deleted markup objects can remain in the PDF; unlimited edit-session file growth is not bounded by that history limit.
- Native Wayland/mixed-DPI, native Save As portal and broad crash/disk-full recovery require further validation. Signed/encrypted PDFs are rejected rather than silently altered.
- x86_64 Linux packages only; ARM64 is not built/tested here.

## Installation

Arch-first: `glyph-arch-x86_64.tar.gz` and `install-glyph-arch.sh`. Alternate AppImage/no-FUSE installer, Debian package and compatibility tarball are included. `SHA256SUMS` covers distribution assets. Publishing this release does not install or launch Glyph, change desktop settings, or modify user PDFs.
