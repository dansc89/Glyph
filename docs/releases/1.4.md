# Glyph 1.4

A smaller, calmer, PDF-first native interface for x86_64 Linux.

## Changes

- Replaced the three-row text-button toolbar with one compact row of native vector icons. Navigation, zoom, fit, page entry and markup tools remain directly available.
- Narrower, resizable sidebar with compact Pages, Bookmarks and Search tabs. Existing oversized sidebar widths are clamped to the new range.
- Smaller title and status bars. Long filenames/status messages truncate rather than wrapping; tooltips expose their full text. Error priority remains intact, with shortcut help behind the help icon.
- Infrequent Auto bookmarks, Hyperlinks and link-visibility commands moved into the More menu. Save/discard, loading, pending-edit and modal guards remain; unsafe Flatten stays disabled.
- Icon tooltips, selected-state outlines, disabled states and named button metadata preserve discoverability. Icons are original font-independent vector drawings, not copied Apple SF Symbols.
- Native rectangle/ellipse editing, shared Undo/Redo, source-preserving previews, verified Save/Save As and retained backups from 1.3 remain available.

## Verification

- The reviewed compact-UI source passed 299 portable Rust tests including ignored regressions, formatting, strict all-target Clippy and optimized compilation. Two private-drawing regressions are explicitly excluded from the portable/hosted run; no private drawing is uploaded.
- The final development binary passed 51 native assertions on owned Xvfb displays and generated PDFs: minimum/large-window layout and actual paper containment, page entry/search focus, mixed-shape saves and backups, read-only refusal/retry, Undo across saves, reopen/delete and same-frame gesture-release Save. Nine display-isolation checks also passed.
- At the same 960×640 test window and scale, canvas area increased from 236,164 to 394,850 pixels² (**67.2% more**), occupying 64.3% rather than 38.4% of the window. At 1600×1000 it occupies 77.0%. These are controlled layout measurements, not frame-rate or universal monitor/DPI claims.
- Independent focused source review passed. Release artifacts are gated on exact-commit GitHub Actions formatting, Clippy, portable tests, optimized build, compact native layout/fit/search checks, viewer regressions, markup save/recovery, synthetic 100-page native save stress, display isolation, runtime dependency checks and packaging.
- Release publication verifies package metadata and loaded ELF code, tests the downloaded AppImage payload on an owned display, and downloads every uploaded asset back to verify SHA256 before publication.

## Limits

This is a UI-focused update, not complete Drawbridge parity or a guarantee of crash-free operation. Synthetic tests do not establish reliability on all architectural/civil drawing sets. OCR, additional markup types/manipulation/styles, reversible Flatten/Unflatten and lossless Reduce remain unfinished. Native Wayland/mixed-DPI, Save As portals and broader crash/disk-full recovery need further validation. Existing 1.3 limitations still apply.

## Downloads

Arch-first `glyph-arch-x86_64.tar.gz` and `install-glyph-arch.sh`; alternate `Glyph-x86_64.AppImage` with its no-FUSE installer; Debian package and compatibility tarball. `SHA256SUMS` covers distribution assets.

Publishing this release does not install or launch Glyph locally, change desktop settings or modify user PDFs.
