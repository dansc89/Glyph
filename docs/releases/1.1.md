# Glyph 1.1

Native PDF viewer and drawing-set navigation improvements. This release does not claim complete Drawbridge parity.

## Changes
- Full-document literal text search with results, highlight navigation, progress and cancellation.
- Internal PDF links, including named destinations; Back/Forward restores the sheet, zoom, pan and fit mode.
- Persistent Fit Page / Fit Width; direct page entry (Ctrl+G); frame-rate-independent cursor-anchored wheel zoom.
- Clickable, virtualized page thumbnails with bounded background work and texture storage.
- Drag-select PDF text and Ctrl+C copying, including Unicode and embedded whitespace. Scanned pages still require OCR.
- Active Omarchy palette integration, light/dark support and live theme changes; Wayland app ID `glyph`. GUI automation uses private X11 displays, not the user's desktop; Hyprland/mixed-DPI behavior is not comprehensively validated.
- Selectable-text sheet-ID detection, automatic bookmark-copy export and cross-sheet linking with duplicate-target rejection and collision-safe output names. These are heuristic workflows, not title-block-zone/OCR/review support.
- Disabled unsafe legacy Flatten: removing annotations without preserving their appearance is not proper flattening. Reversible flattening is not yet available.

## Verification
- Local 158-test suite passed, including ignored real-document regressions and synthetic benchmarks; formatting and warnings-denied Clippy passed.
- Local optimized binary passed 30 isolated viewer checks and five palette checks. GUI verification includes thumbnail navigation and actual PDF text copied into the native clipboard.
- Distribution packages are produced by GitHub Actions on Ubuntu 24.04, with runtime-dependency checks, tests, optimized compilation, GUI smoke/regression checks, and checksums.
- x86_64 Linux artifacts only. ARM64 is not built or tested in this release.

## Remaining work
Safe in-memory edits, Save/Save As and undo; editable bookmarks and embedded page labels; title-block zones, sheet-number/title review and OCR; reviewed/cancellable batch linking; appearance-preserving reversible flattening; verified lossless reduction.

## Installation
`glyph-arch-x86_64.tar.gz` is the Arch-first package. AppImage, Debian and compatibility tarball assets are also provided. SHA256SUMS covers every distribution asset. No application installation or modification of desktop settings is performed by publishing this release.
